# lumi для Android: телефон, планшет и ТВ

Один APK выбирает сенсорный интерфейс на телефонах и планшетах, управление пультом на Android TV и Huawei Vision S. Нужен свой сервер Lumi в Docker: [инструкция](../README.md).

## Телефоны и планшеты

Android 8 или новее, актуальный Android System WebView. Введи адрес своего сервера, затем войди логином и паролем. Мобильный интерфейс использует веб-приложение твоего сервера внутри Android WebView; файловая очередь, разрешения, сохранение, системное меню «Поделиться» и сканирование QR работают через Android. Обновления интерфейса приходят вместе с сервером.

В профиле появляется пункт **Приложение Android**. Здесь можно добавлять фотографии и видео в постоянную очередь, видеть ход передачи и ошибки, повторять неудачные задания, приостанавливать загрузку и выбирать работу только по Wi-Fi.

Автозагрузка изначально выключена. При включении можно выбрать новые файлы или существующую библиотеку, только папку камеры DCIM или всю доступную медиатеку. Доступ к файлам запрашивается при выборе или включении автозагрузки. Android определяет время фоновой работы; периодическая проверка запрашивается раз в 15 минут. Принудительная остановка приложения и ограничения батареи могут задержать выполнение до следующего открытия. Повторные файлы проверяются на сервере до передачи содержимого.

QR на телефоне нужен для подтверждения входа телевизора, вход в мобильное приложение выполняется по паролю. Для внешнего сервера используй HTTPS; HTTP поддерживается для домашней сети.

## ТВ и кэш

ТВ сохраняет альбомы, людей, слайд-шоу, изменение плотности сетки и переход по датам с пульта. Левый край ведёт в верхнюю навигацию, правый открывает таймлайн.

Нативный зашифрованный кэш миниатюр ограничен 256 МБ. Повторный показ проверяет доступ на сервере; защищённые фотографии и оригиналы в него не сохраняются. Веб-интерфейс также использует свой кэш PWA. Это не режим полностью автономной медиатеки.

На Huawei Vision S широкая карточка 496×280 остаётся у ТВ-экрана и в ресурсах для телевизоров. Сенсорные устройства получают квадратную адаптивную иконку. Проверка ресурсов встроена в сборку.

## Сборка, проверки и выпуск

Нужны JDK 21 и Android SDK 35. `build.ps1` выполняет JVM-тесты, сборку, lint, проверку ресурсов и подписи, затем готовит APK и `release/tv/version.json`. Для обновления поверх установленной версии нужен прежний ключ подписи. Приватные ключи в Git не добавляются.

Инструментальные тесты запускаются командой `gradlew.bat :app:connectedDebugAndroidTest` на эмуляторе. Они проверяют выбор иконки, очередь, одновременное создание базы и связку WebView → авторизация → фоновая отправка на локальный тестовый сервер внутри эмулятора. Проверка JavaScript-моста: `node release/test-mobile-bridge.cjs` с доступным модулем jsdom.

После отправки исходников: `python release/publish_github.py --source-commit <SHA> --prerelease`. Бета публикуется отдельно и не меняет стабильный канал ТВ. Без `--prerelease` скрипт обновляет стабильный манифест в ветке `tv-updates`. Выпуск Android не назначается последним серверным выпуском.

Приложение проверяет `https://raw.githubusercontent.com/mikolord/lumi/tv-updates/tv/version.json`, скачивает APK напрямую из GitHub Releases и проверяет пакет, версию, SHA-256 и подпись. GitHub-токен в APK не встраивается.
