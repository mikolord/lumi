# lumi

Личная фототека на своём сервере: фотографии и видео, альбомы и люди, отдельные аккаунты, импорт из Immich, редактор и защищённые разделы.

**Сервер в Docker обязателен.** Android TV и браузер подключаются к твоему серверу; готового общего облака Lumi нет. Для установки приложения и скачивания APK аккаунт GitHub не требуется.

| Платформа | Установка |
| --- | --- |
| Сервер | Docker Compose — инструкция ниже |
| Android TV / Huawei Vision S | [Скачать APK 0.7.3](https://github.com/mikolord/lumi/releases/download/tv-v0.7.3/lumi-tv-0.7.3.apk) |
| Телефон / компьютер | Открой свой сервер в браузере; можно установить как PWA |
| iOS | Отдельное приложение готовится. Пока доступна PWA через Safari |

Все выпуски: [GitHub Releases](https://github.com/mikolord/lumi/releases).

## Установка сервера

Нужны Docker Engine с Docker Compose и место для библиотеки.

```sh
git clone https://github.com/mikolord/lumi.git
cd lumi
cp .env.example .env
```

В `.env` задай:

- `PHOTO_ORIGIN` — адрес, по которому будешь открывать сервер, например `http://192.168.1.100:8098`.
- `PHOTO_DATA_PATH` — постоянную папку для библиотеки, аккаунтов и настроек.
- `PHOTO_IMPORT_PATH` — папку для импорта исходников; контейнер читает её без записи.
- `PHOTO_FACE_TOKEN` — случайный секрет для внутреннего сервиса распознавания. Создай его командой `openssl rand -hex 32` и вставь результат в `.env`.

```sh
docker compose up -d --build
```

При первой сборке загружаются зависимости и проверенные по SHA-256 модели распознавания лиц. После запуска открой указанный адрес, создай первого администратора. Дальнейших пользователей создаёт администратор. Для установки PWA на iPhone, камеры QR и ключей доступа нужен HTTPS.

Не удаляй каталог данных при обновлении. Перед обновлением сервера сохраняй резервную копию.

## Android TV

Установи APK из раздела Releases, введи адрес своего сервера и войди паролем или по QR. Для QR на авторизованном телефоне: Профиль → Устройства и вход по QR. Телевизор хранит кэш миниатюр локально с проверкой доступа; оригиналы загружаются с твоего сервера.

Проверка версий и скачивание APK идут **напрямую из публичного GitHub**, без сервера-посредника. Перед установкой проверяются SHA-256, имя пакета, версия и подпись. Для самих фотографий сервер Docker по-прежнему нужен.

Слева от крайней карточки можно перейти в верхнюю навигацию; справа — открыть переход по датам. Исходники клиента: [`android-tv/`](android-tv/).

## Обновление сервера

Профиль администратора → Сервер → Обновления. Стабильные серверные версии имеют теги `vX.Y.Z`, версии ТВ — `tv-vX.Y.Z`. Обновления кода сохраняют данные и предыдущую версию. Новые зависимости или изменение `RUNTIME` требуют повторной сборки контейнеров.

Обновление через Docker:

```sh
git pull --ff-only
docker compose up -d --build
```

## Возможности

- Медиатека с изменением плотности сетки, выбором нескольких файлов и переходом по датам.
- Альбомы, обложки, избранное, скрытые и недавно удалённые файлы.
- Имена людей, объединение и исправление совпадений распознавания.
- Импорт из Immich с прогрессом и повтором ошибок.
- Сессии устройств и вход на ТВ по QR.
- Локальная обработка лиц в отдельном контейнере без публичного порта. Видео в распознавании пока не участвуют.

## Разработка и выпуски

Сервер: Python 3.12, `requirements.txt`. Для сборки ТВ нужны JDK 21, Android SDK 35 и исходный ключ подписи для совместимого обновления существующих установок. Ключи, `.env`, пользовательские файлы и кэш не входят в репозиторий.

Серверный пакет: `python scripts/build_release.py`. ТВ: `android-tv/build.ps1`. Инструкция выпуска клиента находится в [`android-tv/README.md`](android-tv/README.md).
