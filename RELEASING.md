# Совместный выпуск сервера и Android

Общий публичный репозиторий: https://github.com/mikolord/lumi, основная ветка `main`.
Сервер и Android имеют отдельные номера версий. Изменения веб-интерфейса автоматически
доступны мобильному клиенту с подключённого сервера; пересобирать APK для каждой
правки CSS или JavaScript не требуется. Изменения Android-кода требуют нового APK.

Перед работой обнови `origin/main`, проверь статус рабочей папки и используй отдельную
ветку или worktree. Перед публикацией сверь новые коммиты других разработчиков.
Не отменяй чужие изменения, не меняй исходный ключ подписи Android.

## Серверный выпуск

После проверок, коммита и отправки исходников:

```sh
python scripts/build_release.py
python scripts/publish_release.py
```

Публикация сервера теперь автоматически прикладывает последний опубликованный APK
из `android-v*` или `tv-v*` и файл `android-version.json` к серверному релизу.
Загрузка APK проверяется по SHA-256. Существующие файлы не заменяются.
В описании сохраняются серверные изменения и добавляется ссылка Android с пометкой
«бета», если исходный выпуск тестовый. Номер серверного выпуска не становится
номером Android. Если синхронизация завершилась ошибкой после публикации сервера,
исправь причину и повтори команду синхронизации ниже.

## Android

Проверки, сборка и отдельная публикация описаны в [android-tv/README.md](android-tv/README.md).
После публикации нового APK можно прикрепить его к текущему серверному релизу:

```sh
python scripts/sync_android_release.py --server-tag v0.76.1 --android-tag android-v0.8.0-beta1
```

Если APK к этому серверному выпуску уже прикреплён и отличается, синхронизация
откажется его заменять: используй новый серверный выпуск или отдельную страницу
Android. Повтор команды с теми же файлами безопасен.

`/releases/latest` предназначен для стабильного сервера. Android-релизы используют
`make_latest=false`. Беты Android не меняют стабильный канал `tv-updates/tv/version.json`.
Стабильный канал обновляется только при отдельном проверенном стабильном выпуске
Android. Приватные ключи и токены не публикуются.
